# Learning Automatas Via Active, Passive and Deep Learning
This project looks at how various learning methods learn reactive systems in order to bridge the gap between State Space Machines and Formal Methods.
## Initial SyntComp Test
To initially understand these results, we use a set of syntcomp examples and extract their relative sample complexities. 
### In order to run this experiment install Spot (≥ 2.14.1)
### Run TLSF_tester.py <TLSF File>
The sample complexity for active and passive learning will be printed out in the terminal
